# Julia simulations

Julia code for running the bioenergetic food-web (BEFW) simulations used in this study.

The simulation scripts are in [script/](script/), and the model functions are in [src/](src/). The simulation data are available [here](https://drive.google.com/drive/folders/1vuBML3ansiDTvnmsaNT4rXGz0y3qhUXY).

Source: [BecksLab/rewilding2023](https://github.com/BecksLab/rewilding2023/tree/125888592b61cc0b8c5329d8dc756646d6c30680).
